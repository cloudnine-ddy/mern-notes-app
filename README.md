# MERN Notes App

A clean and modern full-stack notes application built with the MERN stack (MongoDB, Express, React, Node.js).

## Overview

This project is a notes app where users can sign up, log in, create, edit, and delete notes. It demonstrates a complete MERN workflow with frontend UI, backend API, authentication, and database storage.

## Features

- User authentication with signup and login
- Create, edit, and delete notes
- Responsive React user interface
- RESTful API built with Express and Node.js
- MongoDB data storage for users and notes

## Tech Stack

- MongoDB
- Express
- React
- Node.js
- Tailwind CSS
- Vite

## Project Structure

- `backend/` - server files, API routes, models, and configuration
- `frontend/mern-notes-app/` - React application, components, pages, and styles

## Getting Started

1. Install backend dependencies:
   ```bash
   cd backend
   npm install
   ```
2. Install frontend dependencies:
   ```bash
   cd ../frontend/mern-notes-app
   npm install
   ```
3. Start the backend server:
   ```bash
   cd ../../backend
   npm start
   ```
4. Start the frontend application:
   ```bash
   cd ../frontend/mern-notes-app
   npm run dev
   ```
